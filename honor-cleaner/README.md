# Honor Cleaner

Lightweight native Android app manager tailored for older Honor/Huawei phones (Android 8+).

## What it does
- Lists installed user and system apps.
- Search and filter installed apps.
- Opens Android's app-details screen to clear cache/data or disable/uninstall where Android permits.
- Opens system storage settings.
- Can launch apps and invoke the standard uninstall confirmation for user apps.
- No root, ads, analytics, or network access.

## Honest Android limitation
A normal third-party app cannot silently clear other apps' caches on Android 8. The app therefore uses the OS settings screen rather than claiming to clean data it cannot access. System apps are not removed automatically.
